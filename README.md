# Student Management System

A simple Student Management System built using Node.js, Express.js, EJS, and MySQL.

## Features

* Add students
* View students
* Edit student information
* Search students

## Technologies Used

* Node.js
* Express.js
* EJS
* MySQL
* Git and GitHub

## How to Run

1. Open the project folder in the terminal.
2. Run:

```bash
npm install
```

3. Make sure MySQL is running.
4. Start the application:

```bash
node app.js
```

5. Open the application in your browser:

```text
http://localhost:3000
```

## Student Search

The system allows users to search students by student ID, first name, last name, or course.
